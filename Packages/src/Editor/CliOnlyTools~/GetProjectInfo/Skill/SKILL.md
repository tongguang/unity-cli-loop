# tloop get-project-info

Get detailed Tuanjie project information.

## Usage

```bash
tloop get-project-info
```

## Parameters

None.

## Output

Returns JSON with project information:

- Tuanjie version
- Project name
- Platform settings
- Build target
- Other project metadata
